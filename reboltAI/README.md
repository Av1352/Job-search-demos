## What This Does

Natural-language-driven app generation that turns a single prompt into a full-stack, deployable application.  

**Features:**
- Voice/text to code: describe the app, get HTML/CSS/JS (and backend) in seconds  
- Component library mapping: inputs, lists, charts, forms, dashboards  
- Full-stack output: frontend + basic backend + validation & error handling  
- Multi-platform targets: web-first with paths to iOS/Android  

**Example Flow:**  
“Build a todo list app with priorities” → intent detection → component selection → code generation → preview + deployment options.

## Demo Features

**Build App tab:**
- Prompt presets (Todo, Weather, Expense Tracker, Survey, Team Dashboard)  
- Complexity selector (Simple / Medium / Complex)  
- Outputs app type, generation time, LOC, components, preview mock, and code snippet  

**App Gallery tab:**
- 5 pre-built templates with component badges, LOC, and complexity indicators  
- Quick way to showcase range: from simple lists to small dashboards

## Why It Matters

Traditional development is slow and expensive for simple tools and MVPs.  

This demo illustrates how Rebolt-style generation can:  
- Cut time-to-MVP from weeks to minutes  
- Let non-technical users ship functional prototypes  
- Free engineers to focus on hard problems instead of boilerplate UI plumbing
