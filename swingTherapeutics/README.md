# 💜 Swing Therapeutics - Digital Therapeutic for Fibromyalgia

Production demo of FDA-cleared digital behavioral therapy platform using ACT for chronic pain management.

🔗 **[LIVE DEMO](https://vxanju-demos.streamlit.app/swingTherapeutics)**

## What It Does

FDA Breakthrough Device-designated digital therapeutic delivering Acceptance and Commitment Therapy (ACT) via smartphone for fibromyalgia symptom management—12-week program with daily lessons and interactive exercises.

**Example:** 48yo fibromyalgia patient, pain level 7/10, on Lyrica + Cymbalta → Starts Stanza 12-week program → Daily ACT lessons (15-20 min) → Symptom tracking → Week 12: 42% pain reduction, improved sleep, reduced fatigue → Peer-reviewed Phase 3 results
