## What This Does

Dataset version control with Git-like semantics for ML workflows.

**Features:**
- Compare dataset versions side-by-side (v1.0.0 → v2.0.0)
- Track performance improvements (87% → 94% accuracy)
- Multi-modal support (images, embeddings, text, metadata)
- Team collaboration with complete audit trail

**Demo Scenario:**
Medical imaging dataset evolving through 3 versions:
- v1.0.0: 10K samples, 87% accuracy
- v1.1.0: 15K samples, 91% accuracy (+4%)
- v2.0.0: 20K samples, 94% accuracy (+3%)

---

## Why It Matters

**Problem:** "Which dataset version trained this model?" → Unknown  
**Solution:** Track every dataset change, reproduce any experiment

**Use Cases:**
- Medical imaging research (HIPAA-compliant audit trails)
- Autonomous driving (version sensor data by conditions)
- Computer vision (track annotation quality over time)
