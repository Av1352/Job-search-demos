## What This Does

AI code generator that creates complete, production-ready ML projects from natural language descriptions.

**Features:**
- Natural language → Complete ML pipeline code
- 3 pre-built templates (sentiment analysis, image classification, time series)
- Full project structure (data loading, model, training, evaluation)
- Production patterns (error handling, checkpointing, logging)
- Download code + requirements.txt
- Multi-framework support (PyTorch, TensorFlow, scikit-learn)

**Example:** "Build sentiment analysis for reviews" → Generates 200+ lines of working PyTorch code with BERT fine-tuning, data pipeline, training loop, evaluation → Download and run immediately
