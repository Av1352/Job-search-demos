## Resolution Pipeline

**1. Intake & Classification:**
- NLP analyzes ticket description
- Extracts key entities (error messages, systems, urgency)
- Classifies into category/priority with confidence score

**2. Knowledge Base Search:**
- RAG system searches 10K+ resolved tickets
- Finds similar issues and successful resolutions
- Confidence threshold: 85%+

**3. Automated Resolution:**
- Execute fixes via API integrations:
  - Active Directory (password resets, account unlocks)
  - MDM/Jamf (software deployment, device config)
  - VPN systems (certificate refresh, config updates)
  - Email servers (profile rebuild, mailbox sync)

**4. Verification:**
- Confirm resolution success
- Update user with next steps
- Log for continuous learning
