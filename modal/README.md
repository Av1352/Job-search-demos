## What This Does

Serverless ML platform that lets you run training, inference, and batch jobs on GPUs without managing infrastructure. Scale 0 to 1000s of GPUs, pay per second.

**Features:**
- Serverless GPU provisioning (A100, T4, V100, H100)
- Auto-scaling from 0 to 1000s of replicas
- < 3s cold start time
- Pay per second (no idle costs)
- Pure Python API (no YAML/Kubernetes)
- Built-in monitoring and logging

**Example:** Deploy ResNet50 inference → Modal provisions 2x A100 GPUs → 45ms latency, 250 req/s → Auto-scales based on traffic → Pay only $0.30 per 1K requests
