# 📋 Avallon AI - Insurance Claims Automation Platform

Production demo of full-stack AI agents automating insurance claims operations from intake to resolution.

🔗 **[LIVE DEMO](https://vxanju-demos.streamlit.app/avallonAI)**

---

## What It Does

AI platform automating complete claims workflows for TPAs and insurance carriers—voice AI for intake calls, document processing for medical/repair records, automatic data entry into CMS systems, and vendor coordination.

**Example:** Workers comp claim filed → Avallon voice AI handles intake call → Extracts data from injury photos + medical docs → Categorizes claim type → Updates CMS automatically → Routes to adjuster → 3.2 minutes total (vs 45 min manual) → 93% time savings
