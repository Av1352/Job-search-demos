## What This Does

AI-native psychiatry platform using LLM agents to automate intake, insurance, scheduling, achieving 98.5% automation and 2.3-day wait times vs 7.5-day industry average.

**Features:**
- AI triage with symptom analysis (NLP)
- 98.5% intake automation
- 2.3-day average wait time (vs 7.5 days)
- Insurance-covered, affordable care
- Multi-agent orchestration (5 specialized agents)
- Licensed clinician oversight

**Example:** Patient describes depression symptoms → LLM analyzes → Assesses severity (moderate) → Verifies insurance → Matches with Dr. Kim → Books appointment in 2 days → All in 2.3 minutes
