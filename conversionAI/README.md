## 🏗️ Technical Architecture

### Funnel Analysis Engine
```python
class FunnelAnalyzer:
    def __init__(self, stages):
        self.stages = stages
    
    def analyze(self):
        # Calculate drop-offs
        drop_offs = {}
        for i, stage in enumerate(stages[:-1]):
            next_stage = stages[i + 1]
            drop_off = 1 - (next_stage.visitors / stage.visitors)
            drop_offs[stage.name] = drop_off
        
        # Identify biggest leak
        biggest_leak = max(drop_offs, key=drop_offs.get)
        
        return {
            'overall_cvr': stages[-1].visitors / stages[0].visitors,
            'biggest_leak': biggest_leak,
            'drop_off_rate': drop_offs[biggest_leak]
        }
```

### Recommendation Algorithm
```python
def generate_recommendations(funnel_analysis):
    strategies = []
    
    for strategy, config in OPTIMIZATION_STRATEGIES.items():
        # Score based on impact, ease, cost
        impact_score = config['expected_lift'] * 100
        ease_score = {'Easy': 100, 'Medium': 60, 'Hard': 30}[config['implementation']]
        cost_score = {'Low': 100, 'Medium': 60, 'High': 30}[config['cost']]
        
        # Weighted total
        total_score = (impact_score * 0.4) + (ease_score * 0.3) + (cost_score * 0.2)
        
        # Bonus if targets biggest leak
        if config['impact_stage'] == funnel_analysis['biggest_leak']:
            total_score *= 1.2
        
        strategies.append({
            'name': strategy,
            'score': total_score,
            'expected_lift': config['expected_lift']
        })
    
    # Sort by score, return top 3
    return sorted(strategies, key=lambda x: x['score'], reverse=True)[:3]
```

### Funnel Stage Definitions
- **Awareness**: Landing page view, ad click
- **Interest**: Product page view, read content
- **Consideration**: Add to cart, request demo, sign up for trial
- **Intent**: Begin checkout, fill contact form, download pricing
- **Purchase**: Complete transaction, sign contract

### ROAS Calculation
```python
ROAS = Revenue Generated / Ad Spend

Example:
- Spend: $10,000 on Google Ads
- Revenue: $48,000 from those ads
- ROAS: 4.8x

Target ROAS:
- E-commerce: 4-6x
- SaaS: 3-5x
- B2B: 2-4x (longer sales cycles)
```

### Lift Calculation
```python
Lift % = ((New Conversion - Old Conversion) / Old Conversion) × 100

Example:
- Old CVR: 2.0%
- New CVR: 2.5%
- Lift: ((2.5 - 2.0) / 2.0) × 100 = 25%
```

### Optimization Priority Framework

**1. Fix biggest leak first**

**2. Quick wins early**
- Easy + Low cost + Medium lift > Hard + High cost + High lift
- Build momentum, prove value

- Implement top recommendation
- Track actual lift vs predicted
- Learn and refine
