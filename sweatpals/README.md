# 🏃 Sweatpals - Social Fitness Discovery Platform

Production demo of AI-powered social fitness marketplace connecting users to local fitness events and communities.

🔗 **[LIVE DEMO](https://vxanju-demos.streamlit.app/sweatpals)**

---

## What It Does

Social fitness platform that uses AI to match users with local fitness events, classes, and communities—from run clubs to yoga socials—while providing hosts with tools to grow communities and monetize.

**Example:** New to Austin → Opens Sweatpals → AI recommends "Morning Run Club + Coffee" (98% match) → Joins Wednesday 7am run → Meets 34 people → Finds fitness community → "Daylife replacing nightlife"

---

## Why It Matters

**Problem:** 55% of younger generations seek fitness for social connection, but hard to discover local events  
**Solution:** AI-powered discovery + host monetization tools create "third space" for community

**ROI:** 1M+ monthly users, 30% host revenue increase, $70K average host earnings

## Demo Features
