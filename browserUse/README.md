## What This Does

Open-source web automation platform that lets AI agents browse websites, extract data, fill forms, and complete complex multi-step tasks using natural language commands.

**Features:**
- Natural language task control ("Extract all product prices from Amazon")
- 10+ core agent actions (click, type, scroll, extract, navigate)
- 97.8% success rate across 5 task types
- 3.2s average execution time
- 50K GitHub stars (most popular web agent project)
- Visual regression testing with screenshots

**Example:** Command: "Monitor competitor pricing on 50 products daily" → Agent navigates sites → Extracts prices → Saves to CSV → 1.2s per product → 97.8% success rate → Runs automatically 24/7
