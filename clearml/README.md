## What This Does

Demonstrates **complete ML experiment tracking** using ClearML with a CNN trained on MNIST.

**Features:**
- Auto-magic experiment tracking with just `Task.init()`
- Real-time loss & accuracy logging
- Automatic hyperparameter capture
- Git versioning & reproducibility
- Model versioning and artifact storage
- Side-by-side experiment comparison

**Example:**  
Run 4 experiments with different hyperparameters → ClearML auto-tracks everything → Compare runs → Pick best model

## Why It Matters

**Problem:** ML experiments are hard to reproduce and compare
