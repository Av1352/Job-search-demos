# 🔍 Real-Time ML Model Monitor

Production-ready quality assurance system for machine learning models.

**Built for Centaur AI** by Anju Nandhakumar

## Features

- 📊 Multi-method drift detection (KS test, PSI, JS divergence)
- 📈 Real-time performance tracking
- 🚨 Intelligent alerting system
- 💼 Enterprise-ready architecture

## How to Use

1. Configure settings in the left sidebar
2. Select a drift scenario to test
3. Click "Start Monitoring"
4. Observe real-time drift detection and performance metrics

## Technical Highlights

- **Statistical rigor**: Proper hypothesis testing, not just thresholds
- **Production-ready**: Streaming architecture, modular design
- **Business value**: Clear ROI, compliance-ready, actionable insights
