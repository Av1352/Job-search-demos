# ❤️ Wearlinq - Wireless 6-Lead Cardiac Monitoring Platform

Production demo of FDA-cleared wireless ECG monitoring with AI arrhythmia detection.

🔗 **[LIVE DEMO](https://vxanju-demos.streamlit.app/wearlinq)**

---

## What It Does

First wireless 6-lead continuous ECG monitor (eWave) that pairs with smartphones for real-time cardiac monitoring and AI-powered arrhythmia detection.

**Example:** Patient with palpitations → Wears eWave device (6-lead ECG) → Continuous monitoring for 5 days → AI detects AFib episode → Real-time alert to cardiologist → <48hr diagnostic report → Early treatment → Stroke prevented

---

## Why It Matters

**Problem:** Heart disease kills 1 in 3 Americans, but remote monitoring uses single-lead devices (limited accuracy) or wired Holters (poor compliance)  
**Solution:** 6-lead wireless ECG provides hospital-grade diagnostics with home comfort

**ROI:** 47% early detection improvement, 100K+ potential lives saved annually
