## What This Does

Decentralized identity verification with cryptographic proof.

**Features:**
- Instant verification (2s average)
- 5-point validation (issuer, signature, expiration, revocation, tamper)
- Multi-credential support (8 types)
- Real-time analytics (92%+ success rate)

**Example:** Driver license verification → 5 checks (issuer auth, crypto signature, expiration, revocation, tamper) → 2.1s processing → ✓ Verified with SHA-256 hash

**Credential Verifier:**
