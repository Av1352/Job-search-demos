## What This Does

Developer-focused demo showing how to simulate, measure, and integrate voice agents via a simple API.  

**Features:**
- 4 sample agents: Customer Support, Appointment Scheduler, Lead Qualification, Survey Collection  
- Call simulation at scale (100–10,000 calls) with success rate, latency, and cost metrics  
- API examples for creating agents, starting calls, and handling webhooks/function calls  

**Example Flow:**  
Pick an agent → run a batch of simulated calls → inspect success rates, average latency, and AI vs human cost → review copy‑paste Python snippets to integrate the same pattern in a real backend.

## Why It Matters

Rolling your own stack (telephony + STT + LLM + TTS) is brittle, slow to ship, and hard to maintain.  

This demo illustrates how an API‑first platform like Vapi can:  
- Collapse a 200‑line multi‑vendor integration into a few lines of code  
- Give developers predictable performance and pricing  
- Make voice a first‑class, testable component in any app or workflow
