# 🏭 Dryft - Agentic Operating System for Manufacturing

Production demo of Enterprise Resource Automation platform combining AI agents with mathematical optimization for manufacturing operations.

🔗 **[LIVE DEMO](https://vxanju-demos.streamlit.app/dryft)**

---

## What It Does

Manufacturing operating system that replaces static ERPs with intelligent automation—AI agents that understand context, predict outcomes, and take action (adjusting orders, managing inventory, following up with suppliers) in real-time.

**Example:** Supplier delay hits → Traditional: endless emails, gut decisions, manual adjustments → Dryft: AI agent detects delay → Analyzes impact across production → Automatically adjusts order quantities + safety stocks → Follows up with alternative suppliers → Reschedules production → Decision made in minutes vs days

---

## Why It Matters

**Problem:** Manufacturing runs on 1970s ERPs that plan but don't think—when volatility hits, teams scramble  
**Solution:** AI agents + math optimization create adaptive systems that understand and act
